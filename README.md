# 🚀 Khoi Duc - Blazor WebAssembly Portfolio

A feature-rich personal portfolio and developer utility suite built with **Blazor WebAssembly** (.NET 9 / .NET 10), Fluxor state management, and modern Web APIs.

## 🌟 Key Features

- **Personal Resume & CV**: Interactive multi-lingual resume (English & Vietnamese).
- **Developer Utilities**:
  - JWT Debugger & Luhn Algorithm Checker
  - CIDR & Math Calculators
  - Text, Ascii, Unicode, Hex/RGB, and Memory Converters
  - QR Code Generator
  - SQLite Wasm Client-side Database Integration
  - WebGL Rendering & Canvas Controls
  - Gemini AI Spell Checker integration
- **State Management**: Reactive Fluxor Redux pattern with Redux DevTools support.
- **GitHub GraphQL Integration**: Dynamic repository & project querying.

## 🛠️ Architecture & Tech Stack

- **Framework**: Blazor WebAssembly (.NET 9 / .NET 10)
- **State Management**: [Fluxor](https://github.com/mrpmorris/Fluxor)
- **Database**: Entity Framework Core + SQLite Wasm
- **UI Framework**: Bootstrap 5 + FontAwesome 6 + CSS Isolation
- **Authentication**: OpenID Connect / Auth0 integration
- **Mapping**: BlazorGoogleMaps

## 🚀 Getting Started

### Prerequisites

- [.NET 9 SDK](https://dotnet.microsoft.com/download) or higher

### Run Locally

```bash
dotnet run --project BlazorWasmPortfolioGhAction.csproj
```

Open `http://localhost:5000` in your browser.
